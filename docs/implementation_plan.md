# Implementation Plan (概要)

このファイルは長期計画とロードマップを保持します。Ver0.1 ではプロジェクト土台（初期化）を作成します。

## Ver0.1 (プロジェクト初期化)
- Next.js + TypeScript + Tailwind の雛形
- 最小 Home ページ（タイトル表示のみ）
- 必要な設定ファイル（tsconfig, tailwind, postcss, eslint, prettier）
- `docs/` に基本ドキュメントの雛形を配置
- 完了条件: ローカルで `npm run dev` が起動可能、初回Gitコミット完了

※ 本プロジェクトは Next.js 14 系を採用して開始しています。将来的な Next.js 15 系へのアップグレードは、互換性と新機能の必要性に応じて検討します。
