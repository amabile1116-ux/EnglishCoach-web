# Development Guide (Development Constitution)

このドキュメントは単なる環境構築手順ではなく、プロジェクトにおける「開発の憲法」として位置付けます。以下は全開発者（現時点ではあなたと私）が合意する基本方針です。

- **目的優先:** ユーザー体験と保守性を最優先します。
- **一度に1機能:** 実装は必ず一機能ずつ行い、設計承認を得てから実装します。
- **コミット可視化:** 重要なマイルストーン（Ver0.1 完了など）は必ずコミットとタグで残します。
- **秘密管理:** APIキー等は `.env.local` に保存し、決してコミットしません。
- **障害対応:** 重大なバグが発見された場合、まず `current_task.md` に事象を記載して対応優先度を設定します。

環境構築手順や起動コマンドは下記 `README.md` を参照してください。
